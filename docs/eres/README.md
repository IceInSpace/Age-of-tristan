# Catalogue des ères

Un fichier par ère : technologies, bâtiments, unités, merveilles, intrant critique et questions de cadrage. Tout est au stade de **proposition** tant que ce n'est pas validé ; les décisions sont reportées en tête de chaque fichier.

## Types d'unités et contres de base

| Type | Fort contre | Faible contre |
|------|-------------|---------------|
| Mêlée | Distance (au contact) | Cavalerie en charge, distance à découvert |
| Piques | Cavalerie | Distance, mêlée lourde |
| Distance | Mêlée lente, piques | Cavalerie |
| Cavalerie | Distance, siège | Piques |
| Siège / artillerie | Bâtiments, formations | Cavalerie, unités au contact |
| Blindé | Infanterie | Antichar, aviation, drones |
| Aérien | Blindés, bâtiments | Défense antiaérienne |
| Drone | Blindés, infanterie | Brouillage, défense rapprochée |
