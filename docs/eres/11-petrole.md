# Ère 11 — Ère du pétrole

> Acte I · Période indicative : ~1900 – ~1945 · Niveau de gestion : N2 — Région
>
> **Statut** : proposition, à valider. Repères historiques et chiffrés dans la [recherche](../recherche/technologies-et-armes-par-ere.md).

## Décidé

- **Aviation à rayon d'action** : départ d'un aérodrome, frappe dans un rayon, retour.

## Passage à cette ère

- Technologies clés : **Moteur à explosion** et **Raffinage**.
- Bâtiment requis : **raffinerie**.

## Ressources

- **Nouvelles** : **Pétrole brut**, essence, gazole, fioul, caoutchouc, aluminium
- **Intrant critique** : **Carburant** : environ $2$ L/km pour un char de 1940 ; sans carburant, l'armée mécanisée s'arrête.

## Technologies

| Technologie | Branche | Effet |
|-------------|---------|-------|
| Moteur à explosion | Économie | **Clé** ; véhicules, aviation |
| Raffinage et craquage | Économie | **Clé** ; carburants |
| Char | Militaire | Débloque les blindés |
| Aviation militaire | Militaire | Chasseurs, bombardiers |
| Porte-avions | Militaire | Puissance aéronavale |
| Radar | Militaire | Détection des avions |
| Guerre chimique | Militaire | Gaz de combat ; sanctions diplomatiques |
| Carburants de synthèse | Économie | Charbon → carburant si pas de pétrole |

## Merveilles

- **Barrage hydroélectrique géant** : énergie massive.
- **Ligne fortifiée continentale** : défense des frontières.

## Questions de cadrage

- Les **pannes** et la **consommation de carburant** doivent-elles freiner les blindés comme dans la réalité ?
